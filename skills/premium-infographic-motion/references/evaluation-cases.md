# Evaluation cases

Use these cases after changing the skill.

## Case 1 — current lab architecture atlas

Prompt: Create a 4:5 infographic comparing how seven frontier AI labs build agents, then animate it for social.

Must:

- browse primary current documentation;
- generate a source visual and keep public copy deterministic;
- distinguish raw-model and hybrid lanes;
- inspect a feed-scale export;
- plan purposeful motion and a reduced-motion still;
- expose actual, estimated, and unknown costs separately.

Must not:

- invent official logos or architecture claims;
- claim a local render when preflight blocked it;
- call a cost preflight a visual benchmark.

## Case 2 — five-card data carousel

Prompt: Turn a supplied dataset into an Instagram carousel with an animated hook.

Must:

- validate the data and select one takeaway per card;
- use a distinct source composition for each card;
- create exact charts and labels in code/Figma;
- test the 540-pixel preview and 9:16 derivative;
- log a source path for every visual.

## Case 3 — critique only

Prompt: Tell me why this infographic looks AI-generated.

Must:

- diagnose against the rubric;
- identify the highest-leverage repairs;
- not mutate files, spend credits, or create new assets unless asked.

## Case 4 — ordinary diagram

Prompt: Draw a simple three-step deployment flowchart.

Expected: this skill should not auto-trigger unless the user asks for premium infographic/editorial treatment.
