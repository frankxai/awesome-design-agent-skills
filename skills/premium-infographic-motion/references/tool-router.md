# Production tool router

Choose by job. Do not search for one tool that wins every column.

| Job | Default | Use when | Failure to avoid |
| --- | --- | --- | --- |
| Hero/source image | Native high-quality image generation | Tactile objects, environments, people, materials, editorial depth | Generated public text, fake diagrams, approximate logos |
| Exact static master | Figma or deterministic SVG/HTML | Copy, charts, callouts, reusable series, human refinement | Flattening before QA; invisible connector quota limits |
| Operator variants | Canva from an approved master | Resize, translation, bulk variants, non-designer operation | Treating a template draft as premium art direction |
| Short editorial motion | HyperFrames + GSAP | HTML/SVG-first kinetic type, masks, lines, deterministic frames | Non-seekable effects or uncontrolled CSS time |
| Reusable video system | Remotion | React/data-driven series, typed props, programmatic rendering | Ignoring current license eligibility and render infrastructure |
| Product/web interaction | Motion for React | Component states, layout, gestures, presence | Competing with GSAP on the same property |
| Interactive vector/mascot | Rive | Portable state machines and responsive interactions | Using it for photographic compositing |
| Generated source footage | Higgsfield, Runway, or another current video model | Physical texture, impossible camera moves, characters, environments | Asking generated video to preserve final typography |
| Bespoke human ceiling | After Effects + senior motion designer | Nuanced one-off compositing and custom choreography | Poor automation and expensive variant production |

## Recommended stack by outcome

Premium carousel master:

`research → one generated source per card → Figma/SVG exact overlay → feed-scale QA`

Premium animated social post:

`static master → motion beat sheet → HyperFrames + GSAP → MP4 → phone/silent/reduced-motion QA`

Scalable content factory:

`schema + approved Figma/code system → Remotion props → render queue → automated QA + human final review`

Interactive editorial companion:

`same SVG/component system → GSAP ScrollTrigger for authored sequence + Motion for React for local UI state`

## Tool-comparison protocol

1. Use one brief, fact set, canvas, source assets, and scorecard.
2. Record the exact prompt or code revision given to each lane.
3. Separate raw outputs from repaired outputs.
4. Record wall time, exposed spend, iteration count, editability, and quota failure.
5. Score blind where practical.
6. Label inventory-only and cost-only lanes explicitly; do not rank their visual quality.
