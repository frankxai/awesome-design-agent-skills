# Master image prompt

Use this prompt as a structured source-image brief. Replace bracketed variables. Do not paste research citations or long factual copy into the generated visual layer.

## Source visual for deterministic overlay

Create only the visual source layer for a premium `[aspect ratio]` editorial infographic about `[topic]`. Do not include any words, letters, numbers, logos, watermarks, charts, interface panels, or invented glyphs.

The focal point is `[detailed physical or photorealistic subject/metaphor]`, rendered with `[materials, camera, lighting, texture, environment]`. It should communicate `[one-sentence takeaway]` before annotations are added. Give it `[number]` visually distinct components or connection points corresponding to `[information structure]`.

Composition: reserve deliberate negative space at `[zones]` for later exact typography, diagrams, citations, and brand marks. Use a clean `[background]` with `[palette]`. Mix photorealism with restrained graphic elements physically embedded in the scene: color blocking, registration marks, printed material, labels with no characters, cut paper, cables, rulers, or annotation hardware. Make it dense, tactile, specific, and professionally art-directed.

Avoid: generated text, approximate logos, UI dashboards, generic card grids, blue-neon sci-fi HUDs, floating orbs, gradient sludge, random microtext, decorative clutter, stock-photo posing, and motifs unrelated to the information structure.

The result must be strong enough to anchor a world-class social infographic after deterministic overlays are added.

## Raw-model challenger

When benchmarking image-model authorship, run a second prompt that includes the real title and short labels. Judge it without repair. Compare copy accuracy, factual accuracy, hierarchy, legibility, editability, and provenance against the hybrid lane.

## Card-by-card rule

For a carousel, do not reuse one decorative image behind every card. Generate a distinct visual source for each authored card with a stable world, palette, camera grammar, and recurring signature object. Let each frame’s composition reflect its information role:

- Cover: iconic focal object and hook.
- Mechanism: cutaway, sequence, or annotated relationship.
- Comparison: two or three visibly different systems.
- Evidence: real artifact, chart source, or proof object.
- Takeaway: simplified resolution and intentional negative space.

The deterministic design system—not prompt repetition—creates series consistency.
