# Ultimate brand and design-agent loop

The strongest loop is not “generate → ask the same agent if it looks good.” It
separates authority, maker, deterministic checks, independent visual judgment,
decision ownership, and production proof.

## Canonical sequence

1. **Recover authority:** canonical repository, prior decisions/assets, product truth, rights, constraints.
2. **Capture reality:** current/host desktop and mobile, real workflows, content, proof, category references.
3. **Write the thesis:** one recipient, one job, one promise, one action, one signature proof, anti-references.
4. **Render exactly three directions:** materially different composition, type, imagery, color/materials, and motion posture.
5. **Select once:** named decision owner records the winner and why alternatives lost.
6. **Build masters:** vector logo, verified fonts/rights, semantic tokens, DESIGN.md, templates, asset manifest.
7. **Implement static first:** real copy, proof, responsive hierarchy, components, and failure states.
8. **Critique and refine:** Impeccable/Anthropic/Taste/Emil chosen by task—not all at once.
9. **Run deterministic QA:** detector, Playwright, axe, Lighthouse, links, console, type rendering, provenance.
10. **Inspect rendered truth:** desktop, mobile, 320px/reflow, reduced motion, key states, assets at use size.
11. **Separate responsibility:** maker, verifier, and named approver are different for flagship identity and public production work.
12. **Deploy and prove:** exact commit, preview, production URL, post-deploy inspection, hashes, rollback.

| Deterministic audit | Impeccable detector, Vercel guidelines, Playwright, axe, Lighthouse |
| Authority/release | Starlight Design Intelligence + owning product repo |

## Anti-loop failures

- same agent makes, verifies, and approves;
- direction boards are prose rather than rendered artifacts;
- feedback says “premium/modern” without a changed decision;
- multiple style skills are concatenated until the output becomes contradictory;
- logos ship as generated raster art;
- fonts ship without source and rights evidence;
- screenshots are taken without route, viewport, commit, and post-deploy context;
- production cannot be rolled back.
